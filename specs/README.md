# xigo-web — Specification

What the xigo website must do. The code follows this; where they disagree, the
spec wins (AGENTS.md).

## Sources

- **The design canvas** "xigo.ch Homepage" — four pages (Home, Work, Journal,
  About), dark, minimal, Space Grotesk headings over Inter, one champagne
  accent `#E6C79C`, wireframe placeholders where Blender renders go.
- **The current site, xigo.ch** — the founders, their bios and LinkedIn
  profiles, the contact address, xigo's values, and three published articles.
- **The maintainers' decisions** recorded in `docs/adr/`.
