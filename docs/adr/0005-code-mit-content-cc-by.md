# 0005. Code under MIT, content under CC BY 4.0

- **Status:** Accepted
- **Date:** 2026-11-05
- **Deciders:** Andy Moesch

## Context

xigo works in the open. A website holds two kinds of material: code (templates,
styles, scripts) and content (text, our own images and diagrams). Software
licenses fit prose and images badly. The xigo base constitution §9 sets MIT for
code and CC BY 4.0 for content unless a project decides otherwise.

## Decision

- **Code is MIT** (`LICENSE`), as in Rebel Match.
- **Our written content and our own images are CC BY 4.0.** Reuse with credit
  to xigo.
- **The xigo name and logo are not licensed.**
- **Third-party material** — partner logos, others' photos, quotes — is
  excluded and marked where it appears (constitution §A).

The site footer says so in one line.

## Alternatives considered

- **MIT for everything** — written for software; unclear for text and images.
- **CC BY-NC** — not open by common definitions, and it would block the
  organisations and communities we want to help.
- **CC BY-SA or AGPL** — the share-alike duty adds friction and protects little
  for a website.

## Consequences

- Anyone may reuse our posts and site code, with credit.
- Every third-party item needs permission and a marking.
