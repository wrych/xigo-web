# Architecture Decision Records

One decision per file, numbered in order, never renumbered. The process is the
same in every xigo project (xigOS `docs/adr/README.md`): write the ADR before
the decision lands, keep it to a page, and supersede rather than edit.

## Status values

`Proposed` · `Accepted` · `Accepted, amended by NNNN` · `Superseded by NNNN` ·
`Deprecated`
